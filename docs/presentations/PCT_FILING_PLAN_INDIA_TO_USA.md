## 2. Section 39 Compliance — Critical for Defence-Related Inventions

### What is Section 39?
- Applies to inventions "relating to atomic energy or defence"
- DRQ/SSIS qualifies as defence-related (space domain awareness for IAF)
- **Requirement:** Must obtain prior permission from Indian Patent Office before filing PCT internationally if:
  - No priority claimed (first filing is PCT), OR
  - Less than 6 weeks have elapsed since priority filing in India

### Two Pathways

**Path 1: File Indian Provisional First → Wait 6 Weeks → File PCT**
```
Day 0:   File Indian provisional application (Section 39 not needed for domestic filing)
Day 42:  6-week period elapses → Section 39 restriction lifted
Day 43:  File PCT claiming priority from Indian provisional
```
- **Pros:** Establishes priority date in India
- **Pros:** No Section 39 permission required after 6 weeks
- **Pros:** Lower cost for Indian provisional
- **Cons:** 6-week delay before PCT filing
- **Cons:** IAF submission deadline may be tight

**Path 2: Request Section 39 Secrecy Direction → File PCT Directly**
```
Day 0:   File Indian provisional + request Section 39 secrecy direction
Day 30-60: MoD reviews and grants secrecy direction
Day 31-61: File PCT with Section 39 permission
```
- **Pros:** Application remains secret
- **Pros:** Allows IAF disclosure without losing rights
- **Pros:** No 6-week wait if secrecy direction granted
- **Cons:** MoD approval timeline uncertain (30-60 days)
- **Cons:** May miss IAF deadline

**RECOMMENDED: Path 1 (Indian Provisional + 6-Week Wait)**
- More predictable timeline
- Lower cost
- IAF submission deadline can be negotiated if priority date is established

## 3. PCT Filing Process via IP India (RO/IN)

### Step 1: Create WIPO ePCT Account
- URL: https://pct.wipo.int/ePCT/about-newusers.xhtml
- Free to create
- Required for electronic filing

### Step 2: Prepare Application Documents
For each of the 5 innovations:
- Description (detailed technical disclosure)
- Claims (independent + dependent)
- Abstract (150-250 words)
- Drawings (if applicable)

### Step 3: File via ePCT Module
1. Login to ePCT account
2. Select "Create New IA"
3. Select Receiving Office: **IN-Indian Patent Office** (must select RO/IN)
4. Choose fee reduction entitlement:
   - **Natural Person:** 90% international filing fee reduction
   - **Start-up:** Search fee reduction
5. Select International Search Authority (ISA):
   - **ISA/IN (India):** Lower cost, but longer search time
   - **ISA/US (USPTO):** Higher cost, but US search quality
   - **ISA/EP (EPO):** Moderate cost, European search quality
6. Upload documents
7. Pay fees via NEFT/RTGS

### Step 4: Section 39 Permission (if applicable)
- If filing PCT without Indian priority or within 6 weeks of Indian filing
- Submit Foreign Filing Permission (FFP) application to Indian Patent Office
- Include technical description and justification
- Wait for approval before proceeding
